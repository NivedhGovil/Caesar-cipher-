# Caesar-Cipher

The file `Code.py` has the code for a Caesar Cipher, an encryption tool that encrypts alphabets by shifting their place *k* steps forward. For example, if the key was +1 and the original text was 
**Hello**, the encrypted text would be **Ifmmp**. 

**Steps to use the code**
1. Download `code.py` <br>
2. Run the code in python, VS code or any compiler. <br>
3. Enter the original text, when prompted. <br>
4. Enter the key when prompted. <br> 
5. Your encrypted text will be visible. <br>

# Cryptographic Security Note
The Caesar cipher has a key space of size 26, making it vulnerable to brute-force attacks and frequency analysis. <br>  
This project serves as an educational model for fundamental cryptographic concepts rather than production-grade data security.
