Caesar-Cipher

The `file Code.py` has the code for a Caesar Cipher, an encryption tool that encrypts alphabets by shifting their place k steps forward. For example, if the key was +1 and the original text was 
#Hello
, the encrypted text would be Khoor. 

#Steps to use the code
1.Download code.py
2.Run the code in python, VS code or any compiler. 
3.Enter the original text, when prompted.
4.Enter the key when prompted. 
5. You encrypted text will be visible.
